# US HUNT

A single-file Python CLI tool that spins up a local HTTP server and exposes it publicly through Cloudflare's Quick Tunnel while logging every visitor's real IP and requested path in real time.

## Features

- **Single file** - `us_hunt.py`, no installation, no dependencies.
- **Standard library only** - no `pip install` required.
- **Instant public URL** via [Cloudflare Quick Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/).
- **Real visitor IP capture** using the `CF-Connecting-IP` header (falls back to socket address locally).
- **Live logging** to `visitors.log` - every request printed to console and appended to disk.
- **Interactive menu** - no flags to memorize.
- **CSV export** - turn logs into structured data in one click.
- **Built-in HTML editor** - create and edit served pages without leaving the tool.
- **Cross-platform** - Linux and macOS fully supported, Windows works with minor caveats.

Usage

```bash
git clone https://github.com/<your-username>/us-hunt.git
cd us-hunt
python3 us_hunt.py
```

You'll see the interactive menu:

```
+------------+-------------------------------------+
| 1          | Start Server & Tunnel               |
| 2          | View Live Visits (with details)     |
| 3          | Show Visit Log (Last 50)            |
| 4          | Export Logs (CSV)                   |
| 5          | Clear Logs                          |
| 6          | Settings                            |
| 7          | Help                                |
| 8          | Edit HTML File & Set Default        |
| 0          | Exit                                |
+------------+-------------------------------------+
```

Quick start

1. Option 8 - create or edit an HTML page. A default template is generated if the file doesn't exist.
2. Option 1 - pick the file, and US HUNT will:
   · Start an HTTP server on localhost:8080
   · Launch a Cloudflare Quick Tunnel
   · Print your public https://<random>.trycloudflare.com URL
3. Share the URL. Watch option 2 for real-time visits, or option 3 for the last 50.

---

Directory Layout

```
us_hunt.py
Files/                 <- your HTML pages live here (auto-created)
visitors.log           <- one line per request
logs_export.csv        <- generated by option 4
```

All paths are derived from the script's own location - you can run it from anywhere.

Log Format

Each request appends a line to visitors.log:

```
[2025-01-15 14:32:07] IP: 203.0.113.42 -> /index.html
[2025-01-15 14:32:09] IP: 203.0.113.42 -> /style.css
```

Exporting to CSV (option 4) produces:

Timestamp IP Path
2025-01-15 14:32:07 203.0.113.42 /index.html
2025-01-15 14:32:09 203.0.113.42 /style.css

Troubleshooting

cloudflared not found in PATH

Install it (see above) and reopen your terminal.

No public URL appears after 30 seconds

US HUNT prints diagnostics. Common causes:

· ISP blocking Cloudflare or trycloudflare.com
· Broken IPv6 - try disabling IPv6 or forcing IPv4
· Missing proxy - set HTTPS_PROXY if you're behind a corporate network
· DNS failure - check dig api.trycloudflare.com

Manual checks:

```bash
dig +short api.trycloudflare.com
curl -4 -v https://api.trycloudflare.com
env | grep -i proxy
```

Port 8080 already in use

Kill the process holding the port, or change PORT in the script:

```bash
sudo lsof -i :8080
```

How It Works

1. http.server.HTTPServer binds to 0.0.0.0:8080 with a custom TrackingHandler.
2. The handler reads the CF-Connecting-IP header (Cloudflare injects it) to get the real visitor IP, falling back to the socket address for local traffic.
3. cloudflared tunnel --url http://localhost:8080 creates an outbound-only tunnel and prints a trycloudflare.com URL.
4. Every request is logged to console + visitors.log before being served.

No inbound ports need to be opened. No Cloudflare account required.
