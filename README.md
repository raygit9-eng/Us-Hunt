US HUNT

Cloudflare Tunnel Testing Utility

A lightweight Python utility for serving HTML files locally and exposing them through a temporary Cloudflare Tunnel.

Designed for local development, demonstrations, and authorized security testing.

---

Overview

US HUNT provides a simple interface for:

- Serving HTML files through a local Python HTTP server
- Creating a temporary Cloudflare Tunnel
- Monitoring HTTP requests during authorized testing
- Managing local HTML files
- Exporting test logs
- Viewing and clearing local logs

The project is designed to be simple enough to run on Termux while remaining compatible with common Linux, macOS, and Windows environments.

Features

Local HTTP Server

Serve HTML files directly from the "Files/" directory using Python's built-in HTTP server.

Cloudflare Tunnel

Create a temporary public endpoint through Cloudflare Tunnel without configuring port forwarding.

Request Monitoring

Monitor requests generated by your own testing environment directly from the terminal.

HTML Management

Create and edit HTML files from the built-in menu using Nano.

Log Management

View recent test activity, monitor logs in real time, clear existing logs, and export records to CSV.

Lightweight Design

The project uses a small number of dependencies and can run on low-resource environments such as Termux.

Installation

Clone the Repository

git clone https://github.com/raygit9-eng/Us-Hunt.git

---

Requirements

Before running US HUNT, install:

- Python 3.6 or newer
- Cloudflared
- Nano (optional)

---

Python Installation

Termux

pkg update && pkg upgrade
pkg install python

Debian / Ubuntu / Kali

sudo apt update
sudo apt install python3 python3-pip -y

Arch Linux

sudo pacman -S python python-pip

macOS

brew install python

Windows

Install Python and make sure that the Python executable is added to your system "PATH".

Verify the installation:

python3 --version

Cloudflared Installation

Termux

pkg install cloudflared -y

Debian / Ubuntu / Kali

sudo apt update
sudo apt install cloudflared -y

Arch Linux

sudo pacman -S cloudflared

macOS

brew install cloudflared

Windows

Using Chocolatey:

choco install cloudflared

Verify the installation:

---

Configuration

The primary configuration values are located in "us_hunt.py":

PORT = 8080
BASE_DIR = "Files"
LOG_FILE = "visitors.log"

Port

Controls the local HTTP server port.

Base Directory

Specifies where HTML files are stored.

Log File

Specifies the local file used for test activity logs.

Troubleshooting

Cloudflared command not found

Check whether Cloudflared is available:

which cloudflared

Then verify:

cloudflared --version

Python command not found

Try:

python3 --version

If Python is not installed, install it using the instructions above.

Nano does not open

Install Nano or change the editor used by the HTML editing function.

For example, on systems with another editor available, you can modify the corresponding editor command in "us_hunt.py".

Port 8080 is already in use

Change the configured port:

PORT = 8081

Then restart the application.

Security and Privacy

US HUNT should only be used in environments where you have permission to perform testing.

Do not use the project to collect information from visitors without their knowledge and authorization.

Keep generated logs secure and remove them when they are no longer required.
